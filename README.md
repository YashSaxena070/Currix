## 📋 Overview

Currix is an AI-powered resume analysis platform that helps job seekers optimize their resumes for better job matching. The application analyzes resumes against job descriptions, provides ATS (Applicant Tracking System) scores, detects plagiarism, and offers AI-powered improvement suggestions.

## ✨ Features

- **User Authentication** - Secure JWT-based authentication with email verification
- **Resume Analysis** - Upload and analyze resumes in multiple formats
- **ATS Score Calculation** - Get compatibility scores for Applicant Tracking Systems
- **Plagiarism Detection** - Identify potential content duplication issues
- **AI-Powered Suggestions** - Receive intelligent recommendations for resume improvement
- **Cloud Storage** - Resume and image storage via Cloudinary
- **Responsive UI** - Modern, mobile-friendly interface

## 🛠️ Tech Stack

### Backend
- **Java 21** - Core programming language
- **Spring Boot 3.x** - Application framework
- **Spring Security** - Authentication & authorization
- **JWT** - Token-based authentication
- **MongoDB** - NoSQL database
- **OpenAI API** - AI-powered analysis and suggestions
- **Cloudinary** - Cloud storage for images and files
- **Maven** - Dependency management
- **Brevo/SendGrid** - Email services

### Frontend
- **React 18** - UI library
- **Vite** - Build tool and development server
- **JavaScript (ES6+)** - Programming language
- **CSS3** - Styling
- **ESLint** - Code linting
- **HMR (Hot Module Replacement)** - Fast refresh during development
